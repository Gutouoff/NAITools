# Langbai 界面与 Rust 服务迁移

## 基线与边界

用户要求：先完整复用 Langbai 的 UI 和交互逻辑，后续再做微调。不再把自定义的近似界面称为复刻版。

- 原版前端：本地 Langbai 2.4.4，冻结于 `desktop/langbai/`，文件内容由 SHA-256 清单保护。
- 布局、样式、组件、状态管理及现有文案直接复用；没有复制 Electron 服务实现。
- 界面仍由原版 React 渲染，桌面宿主与服务由 Rust/Tauri 提供。这不是所有界面组件改用 Rust 编写。
- 允许的产品标识覆盖仅限 APP_NAME、APP_VERSION、PROJECT_REPOSITORY；源快照不修改。
- API 清单通过 TypeScript AST 生成：244 个契约成员，209 个在原版前端中被直接引用。经别名/依赖注入访问的成员不计入直接引用数。
- 尚未连接的原生功能必须明确失败，不返回伪造的成功结果，也不发送付费请求。
- 已有数据库、任务记录、凭据命名空间和应用标识保持不变。

## 推进顺序

1. 冻结原版源文件、补齐依赖、建立接口清单与完整性测试。
2. 独立构建原版界面；接通 Rust 本地设置、启动生命周期及最小初始化契约。
3. 历史记录、元数据、本地图像读取与导入；参考文件与预设。
4. 逐项核对生成参数和服务契约，接通文生图、图生图、氛围迁移及人物参考。
5. 连接配置、多个账号/第三方提供商、完整错误与计费确认。
6. 按原版交互建立截图、拖拽、提示词输入、模式切换和历史记录回归。

不把第 1/2 阶段称为“100% 完成”。在原生适配通过验证之前，稳定入口保留已有 PC 界面，原版迁移通过单独构建入口验证。

## 独立迁移入口：本轮进展

- 原版 renderer 已通过独立 TypeScript / Vite 构建；主资源从根入口加载，原版相对图标路径在生产 CSP 下可用。
- 11 个原版方法已有实现：10 个 Rust 宿主适配（设置读取 / 单项读写、首次运行状态、完成设置、凭据存在状态、最小化 / 最大化 / 关闭），1 个原版打包资源方法（内置反推模板）。后者按需加载，不是 Rust 原生服务。
- 设置使用原版 109 项默认值与稀疏覆盖；仅 29 项本地 / 界面 / 提示词设置允许写入。凭据、服务端点和未接通的功能设置明确拒绝；不会把设置保存成功冒充对应服务可用。
- SQLite v4→v5 在原数据库中新增设置表；临时数据库测试验证草稿、历史、额外账号、凭据版本、绘图预设和未核对任务均保留。读取损坏设置明确失败，不用默认值覆盖原数据。
- 多个原版事件订阅可注册与取消，但尚无对应原生事件生产者，**不计入服务完成度**。可选且未实现的接口保持缺失；必需但未实现的接口明确失败。
- 保留已有凭据 namespace，只返回凭据是否存在及 stale 标记；不生成账号等级、余额或虚假登录状态。不向 renderer 返回 Token；原生存在状态查询沿用凭据管理器读取并清零的既有实现。
- 隔离浏览器回归覆盖左右分隔拖动 / 双击复位、提示词高度指针与键盘调整、生成模式互斥、模式切换保留提示词、凭据字段可编辑、设置主题及未接通生成拒绝。没有访问用户数据或服务商。
- 本轮 55 项前端测试、60 项 Rust workspace 测试通过；独立迁移 debug 原生编译通过，但**没有启动 EXE**。

### 尚未接通

原版的文件导入 / 历史列表 / 元数据服务、参考文件与预设库、账号与第三方提供商切换、文生图 / 图生图 / 氛围迁移 / 人物参考，以及原生事件流仍需逐项迁移。旧版自定义工作台已有的后端代码，不等于原版界面已接通。API 字段必须继续按冻结契约及协议证据核验，OpenAI Images 暂不转换。

原生数据保存、真实启动耗时与资源使用未通过本轮验收。浏览器合成 IPC 只证明渲染与交互回归，不证明默认 AppData 可写。收费调用 0 次，费用 $0。

### 数据库与回滚

应用标识仍为 com.langbai.studio.pc.preview，不更换持久路径、删除数据库或重置任务。**v4 旧二进制不能读取已升级为 v5 的数据库**；在运行新版前应关闭应用并完整备份数据库及其 WAL / SHM 等关联文件，必要时用一致备份恢复。不要只用 git checkout 或替换旧 EXE 当作数据回滚。本轮未打开或升级真实用户数据库。

## 验证命令

在 desktop 目录运行：

- npm run check:langbai-source：验证源快照完整性与接口清单无漂移。
- npm run inventory:langbai：根据冻结源码重新生成接口清单。
- npm run build:langbai：构建独立原版界面；不替换默认入口。
- npm run test:browser:langbai：在迁移预览服务器启动后运行隔离浏览器回归，需指定 PLAYWRIGHT_MODULE / BROWSER_EXECUTABLE。
- npm run desktop:build:langbai：原版迁移 debug 构建；本机原生启动尚未验收，不作为正式版使用。
