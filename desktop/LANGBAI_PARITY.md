# Langbai 界面与 Rust 服务迁移

## 基线与边界

用户要求：先完整复用 Langbai 的 UI 和交互逻辑，后续再做微调。不再把自定义的近似界面称为复刻版。

- 原版前端：本地 Langbai 2.4.4，冻结于 \desktop/langbai\，文件内容由 SHA-256 清单保护。
- 布局、样式、组件、状态管理及现有文案直接复用；没有复制 Electron 服务实现。
- 界面仍由原版 React 渲染，桌面宿主与服务由 Rust/Tauri 提供。这不是所有界面组件改用 Rust 编写。
- 允许的产品标识覆盖仅限 APP_NAME、APP_VERSION、PROJECT_REPOSITORY；源快照不修改。
- API 清单通过 TypeScript AST 生成：244 个契约成员，209 个在原版前端中被直接引用。经别名/依赖注入访问的成员不计入直接引用数。
- 尚未连接的原生功能必须明确失败，不返回伪造的成功结果，也不发送付费请求。
- 已有数据库、任务记录、凭据命名空间和应用标识保持不变。

## 推进顺序

1. 冻结原版源文件、补齐依赖、建立接口清单与完整性测试。
2. 独立构建原版界面；接通 Rust 本地设置、启动生命周期及最小初始化契约。
3. 历史记录、元数据、本地图像读取与导入；参考文件与预设。
4. 逐项核对生成参数和服务契约，接通文生图、图生图、氛围迁移及人物参考。
5. 连接配置、多个账号/第三方提供商、完整错误与计费确认。
6. 按原版交互建立截图、拖拽、提示词输入、模式切换和历史记录回归。

不把第 1/2 阶段称为“100% 完成”。在原生适配通过验证之前，稳定入口保留已有 PC 界面，原版迁移通过单独构建入口验证。

## 验证命令

在 desktop 目录运行：

- npm run check:langbai-source：验证源快照完整性与接口清单无漂移。
- npm run inventory:langbai：根据冻结源码重新生成接口清单。

## 许可证
