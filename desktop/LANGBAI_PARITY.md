# Langbai 界面与 Rust 服务迁移

## 基线与边界

用户要求：先完整复用 Langbai 的 UI 和交互逻辑，后续再做微调。不再把自定义的近似界面称为复刻版。

- 原版前端：本地 Langbai 2.4.4，冻结于 `desktop/langbai/`，文件内容由 SHA-256 清单保护。
- 布局、样式、组件、状态管理及现有文案直接复用；没有复制 Electron 服务实现。
- 界面仍由原版 React 渲染，桌面宿主与服务由 Rust/Tauri 提供。这不是所有界面组件改用 Rust 编写。
- 允许的产品标识覆盖仅限 APP_NAME、APP_VERSION、PROJECT_REPOSITORY；源快照不修改。
- API 清单通过 TypeScript AST 生成：244 个契约成员，209 个在原版前端中被直接引用。经别名/依赖注入访问的成员不计入直接引用数。
- 尚未连接的原生功能必须明确失败，不返回伪造的成功结果，也不发送付费请求。
- 已有数据库、任务记录、凭据命名空间和应用标识保持不变。

## 推进顺序

1. 冻结原版源文件、补齐依赖、建立接口清单与完整性测试。
2. 独立构建原版界面；接通 Rust 本地设置、启动生命周期及最小初始化契约。
3. 历史记录、元数据、本地图像读取与导入；参考文件与预设。
4. 逐项核对生成参数和服务契约，接通文生图、图生图、氛围迁移及人物参考。
5. 连接配置、多个账号/第三方提供商、完整错误与计费确认。
6. 按原版交互建立截图、拖拽、提示词输入、模式切换和历史记录回归。

不把第 1/2 阶段称为“100% 完成”。按用户要求，默认构建入口现在加载原版 Langbai renderer，停用自定义提示词编辑器；未完成的原生功能仍明确拒绝。旧版源文件仅用于回归及后续服务迁移，不加载到默认界面。

## 默认原版入口：当前进展

- 原版 renderer 已通过独立 TypeScript / Vite 构建；主资源从根入口加载，原版相对图标路径在生产 CSP 下可用。
- 25 个原版方法已有实现：本地设置、首次运行、凭据存在状态、窗口操作、本地图像及元数据快照、历史记录分页 / 日期 / 分组及内置反推模板。历史媒体不再通过历史 IPC 返回整张 base64 原图，而是由受限 `naitools-image` 本地协议按需读取。
- 图像服务支持 PNG / JPEG / WebP 导入、重新加载与清除；保留原始图片字节及全尺寸，不重编码。元数据由冻结的原版 png-meta 解析器按需读取，无可兼容元数据则不返回 metadata 字段。
- 元数据快照在原 AppData root 的 langbai/metadata-snapshot.json 原子保存并恢复；损坏快照明确失败，不覆盖。单独读取 / 保存快照不会替换当前工作区图片。
- 文件选择由原生对话框授权；renderer 仅持有 naitools://imports/ 或 naitools://outputs/ 的受限引用，不接受任意本地路径或外部 URL。沿用 16 MiB、像素与解码内存限制。剪贴板文件与任意路径拖放尚未接通。
- 设置使用原版 109 项默认值与稀疏覆盖；仅 29 项本地 / 界面 / 提示词设置允许写入。凭据、服务端点和未接通的功能设置明确拒绝；不会把设置保存成功冒充对应服务可用。
- SQLite v4→v5 在原数据库中新增设置表；本轮增加 v5→v6 历史分组与归属表，迁移不删除草稿、历史、额外账号、凭据版本、绘图预设或未核对任务。读取损坏设置明确失败，不用默认值覆盖原数据。历史旧记录缺少请求快照时明确显示“缺少生成参数”，不以当前默认参数冒充。
- 多个原版事件订阅可注册与取消，但尚无对应原生事件生产者，**不计入服务完成度**。可选且未实现的接口保持缺失；必需但未实现的接口明确失败。
- 保留已有凭据 namespace，只返回凭据是否存在及 stale 标记；不生成账号等级、余额或虚假登录状态。不向 renderer 返回 Token；原生存在状态查询沿用凭据管理器读取并清零的既有实现。
- 隔离浏览器回归覆盖左右分隔拖动 / 双击复位、提示词高度指针与键盘调整、生成模式互斥、模式切换保留提示词、凭据字段可编辑、设置主题、原尺寸图像显示、实际 PNG 元数据解析及快照、图片清除和未接通生成拒绝。V5 迁移提示通过原版按钮关闭，不修改或跳过原版逻辑；没有访问用户数据或服务商。
- 本轮 63 项前端测试、67 项 Rust workspace 测试通过；默认及独立原版前端构建、冻结源校验通过。release 构建与启动状态见 VALIDATION.md；本轮没有启动原生 EXE。

### 本轮新增：原版历史读取与媒体协议

- 历史列表按稳定游标分页读取，日期使用本地日历边界，分组支持创建、重命名、删除和图片归属切换；删除分组只解除归属，不删除图片、任务或历史回执。
- 历史卡片和查看器使用 `http://naitools-image.localhost/{artifactId}`，仅允许主窗口、GET、受限 ID、outputs 目录内 PNG，16 MiB 上限；不接受任意路径、查询参数或远程转发。CSP 只增加这个精确图片源，未放开互联网连接。
- 历史点击仍是预览行为；参数和种子只在原版“从图像生成 / 变体”动作中显式恢复。

### 尚未接通

原版的历史列表及历史详情联动、剪贴板 / 路径拖放、参考文件与预设库、账号与第三方提供商切换、文生图 / 图生图 / 氛围迁移 / 人物参考，以及原生事件流仍需逐项迁移。旧版自定义工作台已有的后端代码，不等于原版界面已接通。API 字段必须继续按冻结契约及协议证据核验，OpenAI Images 暂不转换。

原生数据保存、真实启动耗时与资源使用未通过本轮验收。浏览器合成 IPC 只证明渲染与交互回归，不证明默认 AppData 可写。收费调用 0 次，费用 $0。

### 数据库与回滚

应用标识仍为 com.langbai.studio.pc.preview，不更换持久路径、删除数据库或重置任务。**v4 旧二进制不能读取已升级为 v5 的数据库**；在运行新版前应关闭应用并完整备份数据库及其 WAL / SHM 等关联文件，必要时用一致备份恢复。不要只用 git checkout 或替换旧 EXE 当作数据回滚。本轮未打开或升级真实用户数据库。

## 验证命令

在 desktop 目录运行：

- npm run check:langbai-source：验证源快照完整性与接口清单无漂移。
- npm run inventory:langbai：根据冻结源码重新生成接口清单。
- npm run build：构建默认原版界面；不加载旧自定义提示词编辑器。
- npm run build:langbai：构建同一原版界面的独立端口配置。
- npm run test:browser：默认端口 1420 的隔离浏览器回归。
- npm run desktop:build：构建内嵌原版界面的 release 程序，无安装包。
- npm run test:browser:langbai：在迁移预览服务器启动后运行隔离浏览器回归，需指定 PLAYWRIGHT_MODULE / BROWSER_EXECUTABLE。
- npm run desktop:build:langbai：原版迁移 debug 构建；本机原生启动尚未验收，不作为正式版使用。
