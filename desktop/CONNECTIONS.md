# 连接配置与中转协议边界

记录日期：2026-10-04。没有写入、发布或回显用户提供的真实 API Key。

## 使用方式

1. 打开「连接与任务」，选择「添加 NAI 账号」或「添加中转站」。
2. 给每个账号 / API Key 设置独立名称。最多 32 套，默认官方账号保留原凭据身份，不能删除，但可删除其凭据。
3. 官方账号使用固定 NovelAI 图像地址与路径；使用 Persistent API Token。中转使用服务商的 API Key。
4. 中转仅支持 **NovelAI 原生兼容协议**：Bearer 认证、NAI JSON 请求、生成结果 ZIP、氛围编码二进制响应。填写 HTTPS 服务地址及文档确认的生成 / 编码路径。路径与服务地址直接拼接；若服务地址含基础路径，也会保留。
5. 「保存配置」只保存普通元数据。再在下方输入密钥并点「保存凭据」；不加 Bearer 前缀。密钥输入框立即清空，Windows 凭据管理器单独保管，不进入 SQLite 或源代码。
6. 返回工作台，在「生成连接」中选择配置。切换连接会清除工作台氛围选择，不删除本地素材。历史恢复若指向已删除配置，必须明确重新选连接，不会暗中改用默认账号。

中转路径不自动填入猜测值；只有 OpenAI Images / Chat 协议的服务不能直接当作原生中转使用。未配置编码路径时，收费编码在读取凭据或提交任务前拒绝。

## 费用与保护

- 每次生成 1 张，步骤 1–28；没有字符参考 / 人物参考接口，不会静默提交额外人物参考。
- 中转的单图 / 首次氛围编码美元金额是用户录入的**估算**，不是余额查询或实时服务报价；未填写则显示费用未知，不表示免费。
- 每次收费操作单独确认。氛围缓存命中不请求远端；未编码不会自动收费编码。
- 缓存按图片、模型、提取参数、连接身份、接口地址 / 路径及内部凭据版本隔离。改名不失效；更换凭据保守失效，防止把另一账号的编码用于当前账号。此时重新编码可能收费，必须再次明确确认。
- 请求前检查本地存储，提交前原子写入付费 journal。请求一旦尝试提交，超时、无效返回或保存失败都按未知结果处理，阻止新付费请求；没有自动重试或重定向。
- 新任务保存提交时的非敏感连接快照（名称、标识、地址、路径、费用估算）；之后编辑 / 删除配置不改变旧任务归属。旧任务缺少快照时明确说明，不伪造归属。

## 本机持久存储限制

目前工具环境启动的 Rust / Tauri 进程，对原 AppData 目录写入仍遇到 Win32 5 / PermissionDenied；同目录 PowerShell 对照写入成功，当前 PowerShell 进程查询 `IsTokenRestricted` 为 false。普通目录 ACL 也未呈现足以唯一解释差异的拒绝项。因此暂不能把问题简单归因于目录权限或沙箱，根因未定。

没有自动改 ACL、关闭安全功能、重置数据库或切到一个空任务目录。请勿通过删除 journal 绕过未核对任务。先在正常桌面启动环境确认读写，再进行限额真实生成验收；本轮消费 $0。
