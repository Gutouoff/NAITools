# NAITools 工作台设计基线

更新：2026-10-04。目标是紧凑、可预测的 PC 生产力工具；M3 仅用于颜色角色和视觉风格，不宣称完整 Material 组件、官方密度标准或无障碍认证。

## 已实现

- 侧边导航：工作台 / 历史记录 / 连接与任务 / 关于；移除技术栈徽章、营销标题与无用页脚。
- 1440 宽三栏：左侧正向 / 负向提示词与草稿，中间结果预览与生成，右侧参数 / i2i / 氛围参考。
- ≤1100 宽切换图标导航，提示词与参数内部滚动；预览和生成按钮保留。Windows 最小窗口 900×640，网页另有单栏 fallback。
- i2i / 氛围参考折叠；保留参考计数、字符数、任务状态等实际有用信息。
- 专业术语：采样步数、提示词引导强度、随机种子、重绘强度、噪声强度；单位明确，不把字符数称为 Token 数。
- 原文 / 分层两份独立保存；当前模式决定提交文本，预览逐字保留权重与重复标签。分层是应用模板，不是 NAI 规则。
- 本地 CSS、系统字体、颜色变量、可见焦点、禁用 / 加载 / 错误状态；无远程字体 / CDN / 持续背景动效。
- 完整项目 MIT 许可、来源与运行诊断放「关于」，诊断计时不冒充完整启动耗时。
- 存储读取失败不显示“没有任务”；已知未知任务和存储错误必须拦截收费操作，确认窗口可以取消且不会发请求。

## 已验证

生产页面 1440×900、900×900、最小 900×640 无横向溢出且生成按钮可见；提示词与负向区不重叠，内部滚动能访问草稿按钮。编辑 / 分层 / 切页保持内容；浏览器禁止真实原生操作；合成 IPC 验证存储失败、凭据失败、未知任务与取消确认；外部 HTTP 和页面脚本错误均为 0。

Windows release 的实际 WebView2 页面与 IPC 通过，已检查工作台截图；没有把网页预览当成原生验收。
