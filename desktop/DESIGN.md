# PC 工作台设计基线：Material 3

日期：2026-10-03。记录后续设计方向；当前占位界面尚未完成 M3 主题。

## 原则

PC 优先、轻量高效。M3 用于视觉规范，不改变 Rust + Tauri + React 架构，不因此改用 Flutter。

- CSS variables 集中维护颜色角色（primary/on-primary、surface/on-surface、surface-container、outline、error）、字阶、间距、圆角和状态。
- 明暗两套固定可复现色板；不在首屏联网取色或下载字体。
- 桌面工作台采用导航 + 提示词/参数区 + 图像工作区；窄窗口折叠辅助面板，不照搬手机布局。
- 紧凑密度是本项目适配取舍，不能把自定尺寸称作官方 M3 标准。
- 核心控件统一标签、禁用/加载/错误状态，提供可见键盘焦点；颜色不是唯一信息载体，遵循 reduced-motion。
- 仅必要状态动效，不采用持续背景动画、大面积模糊或持续重绘。

## 实现边界

先用现有 React + 本地 CSS 完成有限核心控件。M3 不等于必须引入 MUI；新增依赖需要评估体积和可访问性，不宣称任何库默认即完整 M3。

本机字体、精简本地图标、历史分页/按需加载。主题切换不丢草稿，不增加首屏数据库扫描或常驻任务。

## 顺序与验收

色板/tokens/明暗主题 → 核心控件及桌面布局 → 工作台/历史/诊断统一 → 浏览器回归 → 原生性能实测。

验收包含 1440/900px 无横向溢出、键盘操作/焦点、明暗对比度审查、reduced-motion、主题切换保持草稿、首屏无外部 HTTP。比较生产 JS/CSS 改动；原生环境就绪后测发行版启动与整个进程树内存，不以网页效果代替性能结论。

## 官方参考与边界

https://m3.material.io/ 与 https://m3.material.io/styles/color/roles 在 2026-10-03 只读返回 HTTP 200。后者是动态应用，入口可访问不等于逐项颜色规则已完整核验。实现具体组件前继续核验对应官方资料。

本文工程取舍是本项目方案，不是 Google 承诺的性能收益。


## 2026-10-04 实现状态
