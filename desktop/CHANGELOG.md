# 变更记录

## 0.1.0 原版参考预设库 · 2026-10-05

- 默认 Langbai 参考预设库新增 7 个 Rust 兼容接口：保存、读取、删除及分组管理；沿用原版搜索、网格、分页和工作台应用，不修改冻结 renderer。
- 氛围预设应用恢复已保存的信息提取量 / 参考强度；精准预设保存类型、强度、保真度与尺寸，但不接入未经核验的付费生成请求。
- 预设采用独立本地 SQLite 元数据与原始图片文件，不依赖 WebView 缓存，不迁移现有生成数据库或凭据。列表图片使用受限本地协议按需读取。
- 删除分组不删除预设图片；数据库损坏、素材缺失或保存参数缺失明确失败，不覆盖、伪造成功或自动重试。单张图像限制 16 MiB。
- 72 项前端、78 项 Rust 回归通过；隔离浏览器验证原版预设创建、搜索、显示、应用及生成页实际参数。未调用服务商，费用 $0。
- .nairp 导入 / 导出、线上下载、原版生成与多账号服务接线尚未完成；本机 AppData 与真实生图仍待原生验收。

## 0.1.0 默认原版界面与本地图像服务

- 默认构建切回冻结的 Langbai 2.4.4 renderer，停止加载自定义提示词输入框和工作台样式；三栏、提示词高度调整及生成模式交互直接复用原版。
- 新增 7 个原版图像 / 元数据方法与 6 个显式 Rust 命令：PNG / JPEG / WebP 导入、读取、清除，以及元数据快照保存 / 恢复；完整图片保持原始字节与尺寸。
- 元数据按需复用原版解析器，不自行猜字段；缺失元数据保持缺失，快照损坏明确失败、不覆盖、不自动重试。
- renderer 仅持有 owned imports / outputs 引用；格式、大小、像素、MIME 及路径均校验，不扩张成通用文件访问。数据身份与凭据 namespace 不变；SQLite 在本轮由 v5 迁移到 v6，保留原有数据。
- 根目录启动脚本改指 Rust release EXE，删除旧 Electron 回退，并添加入口回归。
- 69 项前端、67 项 Rust 测试及生产构建通过；浏览器回归使用隔离合成 IPC 与本地 PNG fixture，真实 AppData 保存 / 原生启动 / 付费生图仍待验收。费用 $0。
- 原版历史管理、参考预设、多账号及生成服务尚未接通；不称为全部完成。此前记录中的自定义工作台能力不代表当前默认入口能力。

## 0.1.0 原版 Langbai 独立迁移入口

- 冻结 Langbai 2.4.4 renderer 与公共资源，采用独立 TypeScript / Vite / Tauri 构建；不再用自定义近似 UI 代替复刻。React 渲染器原样保留，Electron 服务逐项替换为 Rust。
- 增加显式兼容桥：10 项宿主方法及 1 项原版内置反推模板资源方法；未接通的必需接口拒绝，可选接口保持缺失，不造账号、历史或生成成功状态。
- 原版设置默认值及内置模板从冻结纯模块生成并校验；模板使用独立延迟加载模块，避免动态 JSON 导入在生产构建中的资源路径错误。
- SQLite v4→v5 原位新增设置表，只允许 29 项本地偏好 / 提示词设置写入；密钥、端点和未接通服务设置不写入此表。应用身份、用户数据路径及凭据 namespace 不变。
- 回归验证原版三栏分隔、提示词输入高度、文生图 / 图生图互斥、提示词保留、设置主题与可编辑凭据输入；原版相对图标路径在根入口和生产 CSP 下正常。
- 55 项前端、60 项 Rust 测试及默认 / 原版前端生产构建通过，迁移原生 debug 编译通过；未运行原生应用，没有替换既有 release EXE，本轮费用 $0。
- 默认入口仍保留先前 PC 预览；原版生成、历史、参考和多个 API 配置服务尚未接通。原生 AppData 保存、真实生成与性能尚未验收，不称为 100% 完成。
- 升级后的 v5 数据不能由旧 v4 二进制读取；本轮仅测试临时数据库，真实运行新版前需完整备份数据库及关联 WAL / SHM 文件。

## 0.1.0 生成模式、图像导入与存储错误提示 · 2026-10-05

- 文生图与图生图改为互斥生成模式；仅图生图显示底图、重绘强度与噪声参数，切换模式不删除已选底图。文生图请求不会携带底图。
- 对照旧版 FilePicker，隐藏原生文件输入，仅保留一个样式化选择按钮；保留拖放与粘贴。
- 图像先在本地验证和生成不超过 512 像素的缩略图，再保存原图；失败仍展示文件名、尺寸和“未保存”状态，保留文件供手动重新导入。未保存素材禁止参与生成或氛围编码，不进行隐式重试。
- 参考图批量先完成格式及解码校验；持久化遇到首次失败即停止，其余明确显示未保存。
- 存储错误细分为访问拒绝、只读、占用、磁盘空间不足和数据库损坏；API 设置展示数据位置与手动重新读取入口，失败保留编辑内容和凭据输入。
- 保留原 AppData 数据目录、数据库、任务日志与凭据命名空间；未更改权限、重置数据库或增加临时存储兜底。错误提示改善不代表本机写入限制已解除。
- 前端 47 项、Rust 54 项测试通过，隔离浏览器合成 IPC 回归通过；本轮无收费请求。原生配置保存与真实出图仍待验收。

## 0.1.0 API 设置、作品管理与参考预设库 · 2026-10-04

- API Key / Persistent API Token 可在新建配置、保存配置之前输入；保存凭据时先保存配置，失败时保留输入。
- 用户界面统一称为「第三方提供商」；直接使用 NovelAI 原生请求格式，拒绝 OpenAI Images 路径，不自动转换协议。
- 设置使用二级导航，宽屏居中；作品管理采用日期分类、缩略图网格与详情三栏布局。示例图明确标记，不写入真实历史。
- 新增读取原始 PNG 文本元数据的受限 IPC；缺失字段不补造，暂不支持 stealth metadata。
- 参考预设库支持氛围迁移 / 精准参考图像分类，名称、备注、本地导入、预览和删除。只允许 PNG/JPEG/WebP，限制 16 MB，并校验图像可解码。
- 补齐生产 CSP 对本地 Blob 图像的权限，不放开远程图片、脚本或网络请求。数据库事务结束后释放连接；分类切换清空详情，存储读取失败不伪装为空库。
- 预设暂存于 WebView IndexedDB，尚未迁移到持久文件存储；清理应用缓存可能删除预设，应保留原始文件。尚未支持 .nairp / 已提取氛围文件或应用到工作台，不宣称功能完整。
- 前端 44 项测试、生产构建和扩展浏览器回归通过；浏览器回归包含生产 CSP 下导入、刷新后保留、分类隔离、删除确认与错误状态。本轮无收费请求。
