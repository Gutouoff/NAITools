# 变更记录

## 0.1.0 开发预览 · 2026-10-04

- 当前源码树替换为独立 Windows PC 重构，旧实现和作者来源保留在 Git 历史；本地旧文件不物理删除。
- 产品、窗口、Rust 可执行文件和 npm 包统一改名 NAITools；持久数据和凭据身份不变。
- 工作台改为紧凑三栏，删除技术宣传；整理参数术语，保留原文 / 分层提示词、i2i 与氛围缓存路径。
- 「关于」加入完整原项目 MIT 许可证和可折叠运行诊断。
- 收费任务前置本地存储检查；只读 / 不可用存储拒绝准备付费传输，正式提交仍原子落盘并阻止未知任务。
- 连接与任务页面分开处理凭据和日志状态，读取失败不再误称空任务列表。
- 增加布局、许可、独立连接状态和存储 / 付费拦截回归；Windows CI 更新为新版包名、workspace 测试及 release 构建。

**仍非正式版**：默认 AppData 原生存储验收失败；真实收费生图、i2i、Vibe 尚未验收；冷 / 热启动与旧版性能对照未完成；无安装包 / 签名 / 自动更新。
